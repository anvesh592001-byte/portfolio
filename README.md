# ANVESH — AI × WEB DEVELOPER

A self-contained editorial portfolio site built from the supplied brief.

## Run locally

Open `index.html` directly, or serve this folder with any static server:

```bash
npx serve .
```

## Notes

- Projects without supplied screenshots use clearly labeled original CSS previews.
- HeatRoute and Titan AI use the supplied project screenshots in `assets/`.
- X-Farm AI also uses the supplied agricultural dashboard screenshot.
- The About section uses the supplied portrait of Anvesh Garikamukku.
- No social URLs, email address, live project links, or testimonials were invented.
- The contact form validates and communicates that it needs a real email endpoint; it does not fake a successful submission.
- To connect submissions, replace the submit handler in `script.js` with a real endpoint or form provider.
